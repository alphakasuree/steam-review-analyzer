# 스팀 리뷰 장단점 분석

Windows에서 **BERT 리뷰 분석.cmd**를 더블클릭하면 [웹 분석 화면](http://127.0.0.1:8767/)이 열립니다. 처음 실행할 때는 Python 3.12와 인터넷 연결이 필요합니다.

Steam 게임의 상점 주소를 넣으면 한국어 리뷰를 가져와 5,000구절로 학습한 BERT로 장단점을 분류합니다. 키워드를 선택하면 해당 리뷰의 근거 구절과 원문을 볼 수 있습니다.

- `web/`에는 웹 화면, 서버, 학습된 모델, 학습·평가 코드가 있습니다.
- `web/data/`에는 학습 데이터, 평가 자료, 웹 화면의 저장 표본에 쓰는 리뷰가 있습니다.
- `강의자료/`에는 강의 PDF와 팀 과제 문서가 있습니다.

재학습과 평가 방법은 [모델 설명](web/README.md)에 있습니다.

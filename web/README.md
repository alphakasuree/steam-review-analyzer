# 한국어 BERT 미세조정 실험

기준 웹 버전은 main의 ae97174다. 실험은 experiment/korean-bert 브랜치에서 실행했다. 기준 웹 버전은 TF-IDF를, 8767번 로컬 웹 앱은 BERT를 사용한다.

| 구절 단위 14개 라벨 Macro F1 | TF-IDF | KLUE BERT |
|---|---:|---:|
| 검증 55개 | 0.443 | 0.555 |
| 기존 테스트 69개 | 0.529 | 0.513 |
| 추가 점검 60개 | 0.145 | 0.289 |

AI 라벨을 사용했다. 같은 리뷰가 기존 학습·검증·테스트에 중복되지 않도록 이전 실험의 분할을 재사용했다. 추가 점검 자료는 기존 라벨링에 쓰지 않은 리뷰 중 한글을 포함하는 길이 6~100자의 구절을 고를 수 있는 리뷰에서 추출했다. 무작위 시드 1123으로 리뷰를 섞고 리뷰당 한 구절을 골랐다. 이 표본은 기존 3개 게임에 한정되며 평가 사례가 없는 라벨도 있다. 평가 기준은 모든 자료에서 14개 라벨의 산술평균이고 분모가 0인 경우 해당 F1을 0으로 처리한다. 추가 점검 micro F1은 TF-IDF 0.624, BERT 0.696였다.

KLUE BERT의 앞 11개 층은 고정하고 마지막 트랜스포머 층과 다중 레이블 분류기를 train_5000.csv의 5,000개 구절로 학습했다. 추가 자료는 기존 평가 리뷰를 제외한 게임에서 주제 관련 표현과 일반 구절을 골라 AI로 라벨링했다. 검증 자료에서 16개 학습 시점과 6개 판정 기준을 비교한 결과 6회차와 판정 기준 0.35을 선택했다. 점검 및 테스트 자료는 선택에 사용하지 않았다. 기존 테스트 문구는 과거 오류 분석에서 이미 살펴봤다. 모델별·라벨별 전체 수치는 results.json에 있다.

## 새 게임 평가와 라벨 기준

구체적인 플레이 요소가 재미의 근거이면 게임플레이 긍정을, 일반적인 칭찬이나 가격 만족이면 기타 긍정을 사용한다. 독립적인 평가가 여럿이면 복수 라벨을 허용한다. 경험이나 사건을 언급할 뿐 장단점 판단이 없으면 라벨을 비운다. train_corrections.csv에는 기존 학습 예문의 수정 전후 라벨 11건이 있다. train_supplement.csv에는 원본 리뷰 ID와 보강 구절이 있다.

사이버펑크 2077, 몬스터 헌터 와일즈, 노 맨즈 스카이에서 주제와 관련된 표현으로 후보를 찾고 문맥을 읽어 219개 구절에 AI 라벨을 붙였다. 14개 라벨마다 정답 사례는 17~25개다. 이 표본은 카테고리별 진단을 위한 목적 표본이다. 자연 발생 빈도와 관련 없는 문장에 대한 오탐은 기존 무작위 점검으로 별도 확인한다. 사람의 독립 검수는 아직 진행하지 않았다.

같은 평가에서 1,000개 기준 모델과 재검수 모델의 Macro F1은 각각 0.466, 0.502였다. 현재 평가 자료와 세부 점수는 data 폴더에 있다. 1,256개 모델은 같은 219구절에서 Macro F1 0.590을 기록했다. 안정성 긍정은 20건 중 17건을 맞혔고 게임플레이 긍정 오탐은 35건에서 31건으로 감소했다. 219구절의 이전 오류 분석에 기반해 보강 주제를 선정했다. 5,000개 모델은 기존 219구절에서 Macro F1 0.736, 새 무작위 96구절에서 0.492였다. 같은 96구절에서 1,256개 모델은 0.414였다. 재평가하려면 python web/evaluate_unseen.py web/bert-last-layer.pt web/data/unseen_5000.json 을 실행한다. 새 무작위 점검에는 출력명을 volume_random_5000.json으로 바꾸고 --audit web/data/volume_random_audit.csv를 지정한다. keyword_evidence는 각 게임의 긍정·부정별 상위 세 키워드에 연결된 구절에서 주제와 감정이 정답 라벨과 일치한 건수를 담는다.

## 재현

### 5,000구절 학습 자료

`train_5000.csv`에 재학습에 쓰는 29개 게임의 구절과 실제 학습 라벨을 모았다. 각 행의 app_id와 review_id로 원본을 추적할 수 있다. 기존 1,256개 중 한 리뷰에서 두 구절을 썼으며, 이번에 추가한 3,744개는 모두 서로 다른 리뷰에서 가져왔다. labels의 세로줄은 복수 라벨을 표시한다. 빈 라벨은 장단점 판단이 없는 예문이다.

추가분은 원문과 대조하고 기존 학습·평가 리뷰 ID 및 정규화한 구절의 중복을 제외했다. annotator 값 AI-context인 910개는 문맥을 읽어 선별하거나 교정했다. 나머지는 주제와 감정 표현 규칙에 기존 분류기의 판정이 일치한 구절이다. rules+TF-IDF+BERT가 2,024개, rules+TF-IDF가 621개, rules+BERT가 189개다. 자동 라벨은 기존 모델의 편향을 이어받을 수 있으며, 사람이 검수한 정답과 구분한다.

추가 무작위 점검 자료 `volume_random_audit.csv`는 Sons of the Forest와 Call of Duty의 한국어 리뷰에서 조건을 만족하는 구절을 리뷰당 하나씩 뽑아 게임당 48개에 AI 라벨을 붙였다. 이 두 게임 및 기존 새 게임 점검에 사용한 세 게임은 학습 자료에서 통째로 제외했다. 동일한 정답으로 기존 모델과 새 모델을 비교한다.

저장소 루트에서 Python 3.12 가상환경으로 실행한다.

~~~powershell
python -m pip install -r web/requirements.txt
$revision = '77c8b3d707df785034b4e50f2da5d37be5f0f546'
New-Item -ItemType Directory -Force .bert_model | Out-Null
foreach ($name in 'config.json','tokenizer.json','special_tokens_map.json','tokenizer_config.json','vocab.txt','model.safetensors') {
    curl.exe -fLsS "https://huggingface.co/klue/bert-base/resolve/$revision/$name" -o ".bert_model/$name"
}
$revision | Set-Content .bert_model/revision.txt -Encoding ascii
python web/predict.py "캐릭터 이동이 너무 답답함"
~~~

bert-last-layer.pt에는 학습한 마지막 층과 분류기 파라미터가 들어 있다. 동일 조건으로 재학습하려면 저장소 루트에서 python web/train_bert.py를 실행한다.

## BERT 웹 앱 실행

Windows에서 저장소 루트의 **BERT 리뷰 분석.cmd**를 더블클릭하세요. 새 PC에서는 Python 3.12와 인터넷 연결이 필요하며, 첫 실행 시 패키지와 약 445MB의 기본 모델을 받습니다. 준비가 끝나면 브라우저에서 http://127.0.0.1:8767 이 열립니다. 직접 실행하려면 위의 모델 준비 후 저장소 루트에서 python web/app.py를 실행하세요.

세 게임의 한국어 리뷰를 각각 100개씩 BERT로 분석한 표본을 제공합니다. 상점 주소를 넣고 300개, 1,000개(기본), 2,000개 중 원하는 분석량을 고릅니다. 한국어 리뷰가 부족하면 확보한 만큼 분석합니다. 결과는 .bert_runs/library-v1에 저장되며 같은 게임을 다시 분석하면 최신 결과로 갱신됩니다. 판정과 대표 구절은 AI 예측입니다. 점수 목표 달성 여부는 위 평가표를 참고하세요.
